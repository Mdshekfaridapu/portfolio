# CURSED TECHNIQUE — Jujutsu Kaisen-inspired Portfolio

A responsive, anime-inspired developer portfolio built with plain HTML, CSS, and JavaScript.

## Run it
Open `index.html` in a browser. No build tools or dependencies are required. Google Fonts load online; system fallbacks are included.

## Customize before publishing
Search the project files for these placeholders and update them:
- `[YOUR NAME]` — hero, about section, footer, and email template
- `[YOUR CITY]` — about section
- `hello@example.com` — contact email and JavaScript mailto handler
- Social URLs — GitHub, LinkedIn, Instagram
- Project titles, descriptions, technology tags, and GitHub links
- Skill labels and percentages — set these to your real skills

The sample project cards are design placeholders. Replace them with real work before publishing.

## Interactive features
- Mobile navigation menu
- Domain Expansion overlay (click the button; press Escape or close to exit)
- Scroll reveal animations
- Cursor glow on desktop
- Contact form opens the visitor's default email app with a prefilled message

## Deploy
Upload the files to GitHub Pages, Netlify, or any static web host. The contact form uses `mailto:` and does not send messages through a backend.
